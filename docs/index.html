從科技巨星到跌落神壇——黃仁勳如何深陷醜聞漩渦？
BBC 中文 · 11-12 16:14 · 43
短短幾天內，黃仁勳作為全球科技競賽領軍人物、看似無可撼動的地位便迅速崩塌。
展开全文（中文翻译）

經常穿著黑色皮褸出席股東活動的黃仁勳，曾經可謂擁有一切。他受到華盛頓和北京領導人的拉攏，備受投資者追捧，也被視為忠於家庭的好男人。然而，他在私人感情生活中如搖滾巨星般放縱的一面，最終導致他辭職。

現年63歲的黃仁勳自1985年結婚以來，一直維持這段婚姻。當時距離他創立Nvidia（英偉達／輝達），並憑藉這家公司成為科技界巨星，還有多年時間。他也一直對外塑造自己顧家好男人的形象。

黃仁勳以工作狂和要求嚴格的管理者著稱，對下屬有極高標準。他的一對子女也在公司工作，並獲得晉升。然而，接連曝光的感情糾葛，令他的個人聲譽在本週急劇下滑，也引發外界對其專注程度和判斷力的質疑。

接連被揭發兩段婚外情後，黃仁勳於週四（11月12日）辭職。首先曝光的是他與一名被指是中國間諜的女商人之間的親密關係。消息迅速傳遍全球，引起投資者關注。隨後在週三，又有報道指這名科技業巨頭的掌舵人曾與一名同事發生婚外情。

黃仁勳離職，為近期已經歷動盪的全球股市增添不確定性。Nvidia是美國與中國爭奪科技領導地位的關鍵企業。

黃仁勳的名字，或許不像馬斯克（Elon Musk）或朱克伯格（Mark Zuckerberg）那樣家喻戶曉。
